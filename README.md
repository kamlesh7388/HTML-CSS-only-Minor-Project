# HTML-CSS-only-Minor-Project
A responsive coffee shop landing page build with pure HTML&amp;CSS--practice (minor project) featuring hero , menu, gallery, testimonials, and contact sections. 
<h1>☕ Aanchal Coffee Roasters- Landing page</h1>
<h4>A responsive coffee shop/ roastery landing page build using only HTML & CSS , create as a front-end practice project </h4>
<h1>📍Features</h1>
<h4> <ul><li>Fully responsive design (mobile,tablet,desktop)</li><li>Hero section with background image and overlay</li><li>About section with stats</li><li>Menu section with product cards</li><li>Image gallery grid</li><li>Customer testimonials section</li><li>contact section with form and info </li><li>footer with quick link</li></ul> </h4>
<h1>🎯Purpose</h1>
<h4>This project was build to practice core front-end concepts.</h4>
<h4><ul><li>Semantic HTML structure </li><li>CSS layout techniques (flexbox/Grid) </li><li>Responsive design with media queries </li><li>Styling real-world UI section (navbar, hero, cards, forms, footer)</li></ul></h4>
